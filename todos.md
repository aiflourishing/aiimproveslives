# Next steps

- [x] Create the private `aiflourishing/aiimproveslives` GitHub repository and connect this workspace. Website source belongs in `src/` so the project has one shared home.
- [ ] Agree on a short inclusion standard. Decide what evidence of actual benefit is needed, how to describe scale, and how to handle preliminary or disputed results. Try it against a few contrasting examples before finalizing it.
- [ ] Collect 10–15 strong examples across several fields. Favor clear benefits and credible sources over filling categories. These examples should test both the standard and the page layout.
- [ ] Settle the entry fields and review checklist. Use the same standard for the About page, contribution instructions, and PR template so contributors get consistent guidance.
- [ ] Build the browse page, individual example pages, and About/contribution page. Proposed approach: Astro, Markdown entries, and a static build; no database or accounts. Each example needs a stable link and a useful sharing preview.
- [ ] Add checks for required fields and a successful site build. Require moderator approval before merging submissions. Automated checks can catch omissions; moderators assess the evidence.
- [ ] Choose hosting and connect `aiimproveslives.com`. Decide whether `lasteval.com` should redirect or remain unused. Publish only after checking the site on mobile and desktop.
- [ ] Invite a few friends to submit and review examples. Use their feedback to simplify the instructions and catch unclear decisions.
- [ ] Before public contributions open, make the repository public and configure review permissions. Keep it private during preparation. Choose code and content licenses so reuse terms are clear.
- [ ] Launch and make corrections easy to report. Assign responsibility for checking challenged or outdated entries so the collection stays trustworthy.

Later: easier submissions for people without GitHub accounts, more moderators, and ways to understand which examples people find useful. Revisit these after the first launch.
